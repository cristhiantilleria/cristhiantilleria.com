# Brand

Logo masters for cristhian tilleria. Files without a suffix use `currentColor`, so they take the text colour when pasted inline. `-ink` and `-paper` have the colour baked in.

- `wordmark`: the lowercase name, Inter Tight Bold.
- `wordmark-stacked`: two-line version for square spaces.
- `lockup-signature`: bullet + wordmark + "design + build · new york", for decks, invoices and email.
- `bullet`: the "ct" monogram, the same round bullet as the site header and section markers.

Colours and type match the site: paper `#F4F2EC`, ink `#0A0A0A`, muted `#7D7B75`, Inter Tight and JetBrains Mono. Favicons and the web manifest live in `static/`.
